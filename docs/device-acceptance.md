# 真机验收清单

自动化测不到、要人在真终端、真手机、真编辑器里看的场景，从 P34–P60 各阶段的规格书收在这里（P62j，技术债 #28）。按功能分组，每组里最可能出问题的排在前面。走过的在方框里打勾，记下日期与发现；发现问题照常登记成债或开修。

环境缺省：Windows 11 + Windows Terminal（PowerShell），tau 从源码跑（`npm run tau`），模型用 DeepSeek 官方端点。写着「WSL」的在 WSL 的 tmux 里做（仓库副本见 development.md 的 `scripts/wsl-copy.sh`）。

## 1. 全屏显示与鼠标（Windows Terminal；P62 换了 Ink 8，先看这组）

- [ ] **拖动窗口边改宽度与高度**（P62h）：缩放中与停下后，只有一个输入框、没有残留的边框，对话还在，宽度变了的行重新折好。再用 `--inline` 做一遍：滚动记录里的历史按新宽度重写，输入框不重复。
- [ ] **滚动**：滚轮、PgUp/PgDn 在对话里滚动；滚到底部后新输出继续跟着走；长回复写到一半时滚上去，不被拉回底部。
- [ ] **选择与复制**（P34、P62h）：拖选一段、双击选词、三击选行，到记事本里粘贴，内容与屏幕一致（中文、宽字符、链接文字都对）。
- [ ] **点击**（P34）：点工具块展开与收起；点审批面板的选项；输入 `/` 后用鼠标点菜单里的一项就选中。
- [ ] **Ctrl+F 搜索**（P34）：输入关键词跳到命中处并高亮，Enter 到下一个，Esc 退出。
- [ ] **右边框完整**（P38）：输入框、审批面板的右边框在各种宽度下都在。
- [ ] **标签进度**（P34）：跑一轮时 Windows Terminal 的标签上有进度、标题在转。
- [ ] **链接**（P38）：回复里的链接 Ctrl+点击能打开，显示时不带 `(url)`。

## 2. 输入与按键（Windows Terminal）

- [ ] **Shift+Enter 换行**（P38，依赖 win32-input-mode）：输入框里换行而不是发送；Enter 才发送。
- [ ] **中文输入法候选框**（P38）：用拼音输入法打字，候选框出现在输入框的光标处，不在屏幕底部。全屏与 `--inline` 各看一次。
- [ ] **编辑键**（P38）：Home、End、Delete、Ctrl+←/→、Ctrl+Backspace、Ctrl+Z 撤销在输入框里都按预期工作。
- [ ] **Tab 排队**（P38）：运行中输入一句按 Tab，它排在这一轮之后发出。
- [ ] **右键粘贴**（P38）：右键把剪贴板的文字粘进输入框，多行文字折叠成一个块。

## 3. 剪贴板与图片（Windows）

- [ ] **Alt+V 粘贴截图**（P36）：Win+Shift+S 截一张图，在输入框按 Alt+V，插入临时图片文件的路径；发出后模型能描述这张图。
- [ ] **粘贴文件**（P36）：在资源管理器里复制一个文件，Alt+V 插入它的原路径。
- [ ] **没有图片时**（P36）：剪贴板只有文字时 Alt+V 粘贴文字。

## 4. 通知（Windows）

- [ ] **一轮跑完、等你批准**（P34）：跑一个要审批的命令，切到别的窗口：收到「等你批准」的系统通知；批准后再切走，跑完时收到「完成」。在窗口前时不发。
- [ ] **`ask_user` 的问题**（P35）：窗口不在前台时模型提问，收到通知。
- [ ] **`push_notification`**（P46）：让模型在你不在终端前时发一条推送，Windows 上弹出系统通知。

## 5. MCP 网页登录（P62f 改了 Windows 上打开链接的方式）

- [ ] **`tau mcp login <服务器>`**：对一个 `"auth": "oauth"` 的真服务器（比如 Linear），浏览器打开的授权地址完整（`&` 后面的参数都在，P62f 修掉了在第一个 `&` 处截断），登录后回到本机回调，`tau mcp list --check` 显示连上。`tau mcp logout` 后再连提示重新登录。
- [ ] **服务器要你打开网页**（P44 的 elicitation 网页模式）：对话框显示完整网址与域名，同意后浏览器打开，链接完整。

## 6. 常驻服务与多客户端（Windows）

- [ ] **两个真终端接同一会话**（P58）：在一个 PowerShell 窗口里 `tau`（自动起服务），另一个窗口 `tau -c`：两边互相看到对方发的话、回复与工具输出；一边答了审批，另一边的面板关掉。
- [ ] **关掉起服务的窗口**（P58）：一轮还在跑时关掉第一个窗口，第二个窗口里这一轮照样跑完；`tau serve status` 显示服务还在。
- [ ] **`tau serve stop` 与 `restart`**（P58）：stop 后 `tau serve status` 报没在运行；改了 `~/.tau/models.json` 后 `tau serve restart`，新开的会话用上新模型。
- [ ] **管理员终端**（P58）：「以管理员身份运行」的 Windows Terminal 里开 `tau`，第一行说明不用常驻服务，会话在自己进程里照常跑。

## 7. 手机（P59）

- [ ] **局域网配对**：`tau serve remote on`、`tau serve pair`，手机扫二维码，配对后页面列出终端里正在跑的会话；接上，发一句话，回复边写边显示；答一次审批，终端里的面板关掉。
- [ ] **断网与休眠**：手机锁屏一会儿再打开，页面自己重连并补上这段时间的回复。
- [ ] **拍照发图**：在会话里附一张照片，模型能描述它。
- [ ] **Tailscale**（有的话）：`tailscale serve --bg 7700` 后用 HTTPS 地址打开，同样能配对与使用。

## 8. 编辑器（Zed，P60）

- [ ] **历史里有终端的会话**：Zed 里 tau 的历史列表能看到终端里开着的会话，打开它、发一句话，终端里看到。
- [ ] **审批两边同步**：Zed 里发一句要审批的话，在终端里答，Zed 里的请求消失；反过来在 Zed 里答，终端的面板关掉。
- [ ] **别处发的话**：终端里发的话出现在 Zed 的面板里（Zed 怎么画规范外的更新要真机看）。

## 9. 会话与命令（真终端）

- [ ] **自动标题**（P34）：新会话跑一轮后，`/resume` 列表里显示模型起的标题。
- [ ] **`/handoff`**（P37）：转圈时按 Esc 能取消；不取消时进入新会话，输入框里是 Context / Files involved / Task 结构的提示，`/session` 显示来源会话，原会话 `/resume` 还能回去。
- [ ] **运行中 `/diff`**（P39）：一轮还在跑时 `/diff` 照样显示改动。
- [ ] **会话树里复制**（P39）：`/tree` 里选中一条，复制它的内容并粘贴出来。
- [ ] **Esc 终止钩子**（P35）：配一个 `sleep 30` 的 `PreToolUse` 钩子，触发后按 Esc，钩子被终止、这次调用不执行。

## 10. 真模型（DeepSeek）

- [ ] **提问与钩子**（P35）：TUI 里让模型「问我用哪种方案再动手」，选一项后模型照着做；`PostToolUse` 配 `edit|write` 跑 `tsc`，故意让模型写错类型，它在同一轮看到报错并改好；`PreToolUse` 对 `git push --force` 退出 2，模型收到理由换别的做法。
- [ ] **状态栏**（P37）：配一个输出模型与上下文百分比的状态栏脚本，跑几轮，数字跟着变。

## 11. 网络

- [ ] **MCP HTTP 走代理**（P40）：设 `HTTPS_PROXY` 指向一个本地代理，连一个 HTTP 的 MCP 服务器，代理里看到这条连接；`NO_PROXY` 里的地址直连。
