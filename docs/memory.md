# 记忆：tau 记得什么、记在哪

tau 的长期记忆是几个 Markdown 文件，都在你的用户目录下，不进仓库（P26c，P32 重做，P39 去掉写入上限）。模型自己决定什么值得记，写入不需要审批；你随时可以查看、编辑、清空。

## 三层

| 层 | 文件 | 什么时候用 |
|---|---|---|
| 关于你 | `~/.tau/memory/USER.md` | 所有项目、终端和你自己的微信对话 |
| 这个项目 | `~/.tau/projects/<项目>/MEMORY.md` | 在这个目录里开的会话；网关里你自己的对话（工作目录就是项目） |
| 项目主题 | `~/.tau/projects/<项目>/memory/<主题>.md` | 细节，按需读取，提示词里只列主题名 |

- 你的偏好、称呼、习惯记在「关于你」；项目约定、做过的决定记在「这个项目」；长的细节（部署步骤、某个模块的来龙去脉）放进主题文件。
- 写入不限字数（照 Claude Code 的自动记忆）。但提示词里只放 `USER.md` 和 `MEMORY.md` 各自的**前 200 行或前 25KB**（先到为准），超出的部分下次不会加载。写到接近这条线时，工具结果会提醒模型整理：一行一条，细节放主题文件，合并或删掉过时的条目；超过时写入照样成功，提醒改成「超出部分下次不加载，现在就整理」。主题文件不进提示词，按需读取。
- **网关里的其他人**只有他自己的一份：`~/.tau/gateway/people/<渠道>/<账号>/<对端>/USER.md`。他的对话里看不到你的任何记忆。

## 什么时候生效

每次会话开始时，tau 把三层记忆的当前内容放进系统提示词，**之后这次会话里不再变**（会话中途写入的内容已经落盘，模型从工具结果里知道写了什么，下次会话才进提示词）。这样提示词前缀保持不变，模型服务的缓存不会失效。新会话、`/new`、`/resume`、重启网关都会重新读取。

## 模型用的工具

| 工具 | 作用 |
|---|---|
| `memory_write` | 追加一条：`target` 为 `user` 或 `project`，可选 `topic` 写进主题文件；重复的忽略 |
| `memory_edit` | 把文件里唯一的一段文字换掉；替换成空就是删除 |
| `memory_read` | 读当前内容（不受会话开始时冻结的影响），附带主题列表 |
| `session_search` | 在你自己的历史会话里按关键词找（空格分隔，全部命中），返回日期、会话文件和前后文 |
| `session_read` | 从找到的位置往前后翻 |

都是低风险，任何档位都不需要审批。写入在 TUI 里照常显示一行工具调用，网关里照常有进度消息。

## 找回以前聊过的

`session_search` 搜的是「你自己的」会话：

- 终端里：`~/.tau/sessions/` 下所有项目的会话，加上网关里记为主人的对话。
- 网关里的其他人：只有他自己的对话。

只搜你和模型的正文，不搜工具输出；直接扫描会话文件，不建索引、不调用模型。会话很多时一次最多扫 200MB 或 3 秒，超了会注明「未搜完」，可以用 `since`（`7d`、`2026-10-01`）缩小范围。

## 你自己管理

| 操作 | 作用 |
|---|---|
| `/memory` | 三层的当前内容和用量 |
| `/memory edit [user\|project\|<主题>]` | 在编辑器里改（缺省是项目记忆） |
| `/memory clear [user\|project]` | 清空（会先确认） |
| `/remember <事实>` 或 TUI 里的 `#事实` | 记到项目记忆 |
| `/remember !<事实>` 或 TUI 里的 `#!事实` | 记到关于你的记忆 |

文件就是普通的 Markdown，也可以直接用编辑器打开改。

## 注意

- 记忆当作背景，不当指令：提示词里写明了这一点。但网页里的提示注入理论上可以诱导模型写进奇怪的内容，写入又不需要审批，所以偶尔看一眼 `/memory`。
- 记忆是明文文件，别让它记密码和密钥；密钥放进凭据库（见 [connectors.md](connectors.md)）。
